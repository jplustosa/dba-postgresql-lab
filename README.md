# PostgreSQL Lab — DBA

## Objetivo
Simular administração básica de PostgreSQL.

## Ambiente
- PostgreSQL 15
- Docker

## Atividades
- Setup do banco
- Criação de schema
- Inserção de dados
- Análise de query lenta
- Criação de índice
- Backup e restore 

## Diagnósticos do dia a dia
O laboratório agora inclui um kit de troubleshooting para incidentes comuns de PostgreSQL, com consultas SQL somente leitura e runbooks operacionais.

- Índice dos diagnósticos: [troubleshooting/README.md](troubleshooting/README.md)
- Compatibilidade do kit: PostgreSQL 15–18.
- As guias cobrem conexões, bloqueios, desempenho, capacidade, vacuum e replicação.
